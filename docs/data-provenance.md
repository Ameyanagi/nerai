# Data provenance

## SciPy covariance cross-check

`tests/test_statistics.mojo` pins a nonlinear exponential-decay fixture and
reference covariance generated by `scripts/generate_statistics_fixture.py`.
The generator uses NumPy 2.4.2 (`default_rng`, `linspace`, and array algebra)
and SciPy 1.17.0 (`scipy.optimize.curve_fit`), retrieved on 2026-08-21. Both
upstreams use the BSD-3-Clause license:

- NumPy: <https://numpy.org/>
- SciPy: <https://scipy.org/>

Generate the values with:

```sh
uv run --with numpy --with scipy python scripts/generate_statistics_fixture.py
```

The seed, observations, unweighted and non-uniform-sigma fitted parameters,
row-major covariance, standard errors, reduced chi-squared, and degrees of
freedom are printed as decimal `Float64` values and pinned directly in the Mojo
evidence tests. Regeneration must reproduce those values before a provenance
update is accepted.

## SciPy Gaussian-peak cross-check

`tests/test_curve.mojo` and `examples/gaussian_peak.mojo` pin a noisy Gaussian
peak fixture and reference parameters generated by
`scripts/generate_gaussian_fixture.py`. The generator uses NumPy 2.4.2 and
SciPy 1.17.0, retrieved on 2026-08-21. Both projects use the BSD-3-Clause
license and are available from <https://numpy.org/> and <https://scipy.org/>.

Generate the values with:

```sh
uv run --with numpy --with scipy python scripts/generate_gaussian_fixture.py
```

The seed, spectrum coordinates, noisy observations, fitted parameters, and
standard errors are printed as decimal `Float64` values. Regeneration must
reproduce the values pinned in the front-door test and example.

## Policy

Every future generated artifact must record:

- upstream project and canonical URL;
- upstream version and retrieval date;
- exact file checksums and licenses;
- generator source and command;
- deterministic output checks;
- review notes for semantic or licensing changes.

Generation tools are development dependencies. Consumers install the generated
Mojo data and do not require Python, Rust, C, or another runtime.
